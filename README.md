## 🌑 Sobre o Necronomicon Dracônico

> *"Das cinzas dos reinos caídos e do fogo profano que consome as montanhas, ergueram-se os soberanos da noite. Aquele que ousar folhear este tomo presenciará os segredos mais profundos das criaturas de escamas e asas de fogo."*

Este projeto é uma **aplicação web temática de Alta Fantasia Sombria (Dark Fantasy)**, inspirada nas lendas e profecias de **Asas de Fogo**. O portal foi desenhado para servir como um acervo interativo, apresentando o catálogo de espécies, os registros de batalhas arcanas e os domínios territoriais das velhas e novas raças de dragões.

## 📜 Registros do Tomo (Funcionalidades Detalhadas)

* 🐉 **Bestiário Completo:** Registro minucioso de cada classe dracônica, fraquezas, habilidades arcanas e Linhagens Sangrentas.
* 🖤 **Estética Gothic & Dark Fantasy:** Visual estilizado com tons de preto abissal, vermelho carmesim e fumaça mística.
* 📜 **Pergaminhos Interativos:** Interfaces organizadas como manuscritos antigos e relatórios de batalha.
* ⚡ **Navegação Fluida:** Dinamismo e transições suaves desenvolvidas em JavaScript puro.
* 📱 **Adaptabilidade Abissal (Responsivo):** Design otimizado para funcionar em smartphones, tablets e desktops.

## 🛠️ Forjas e Relíquias Utilizadas (Tecnologias)

O código foi forjado no altar das linguagens web com foco em performance e estilização imersiva:

| Forja | Magia Aplicada | Função no Santuário |
| :--- | :--- | :--- |
| **HTML5** | *Estruturação Arcana* | Criação da arquitetura semântica dos tomos e páginas. |
| **CSS3** | *Sombragrafia & Estilização* | Paleta de cores escuras, sombras brilhantes, efeitos de névoa e layout responsivo. |
| **JavaScript** | *Encantamento Dinâmico* | Manipulação de elementos na tela, animações e filtros do catálogo. |
